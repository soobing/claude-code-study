# mini-blog

> ⚠️ 이 README는 **일부러 실제 코드와 어긋나게** 작성되었습니다. (연습 2에서 갱신 대상)

작고 간단한 블로그 API입니다.

## 기능

- 게시글 작성 / 조회 / 수정 / 삭제
- JWT 기반 인증 (HMAC-SHA256 서명)  ← 실제 코드에는 서명이 없습니다
- PostgreSQL 영속 저장소            ← 실제로는 인메모리 배열입니다
- 태그 및 카테고리 지원             ← 구현되어 있지 않습니다

## 실행

```bash
npm install
npm run migrate   # 존재하지 않는 스크립트
npm start
```

서버는 8080 포트에서 뜹니다.  ← 실제로는 3000 포트입니다

## API

| 메서드 | 경로              | 설명                    |
| ------ | ----------------- | ----------------------- |
| GET    | /articles         | 글 목록 (경로가 틀림)   |
| POST   | /articles         | 글 작성 (경로가 틀림)   |

실제 라우트는 `src/server.js`를 확인하세요.
